# Restoran

## Ishga tushirish

    npm start

Bu bitta buyruq uchta narsani ishga tushiradi:
- API  -> json-server, http://localhost:3000  (/offers)
- WEB  -> sayt,        http://localhost:5000  (shu manzilni brauzerda oching)
- JS   -> webpack --watch (js/ papkasidagi o'zgarishlarni dist/bundle.js ga yig'adi)

Alohida: `npm run server`, `npm run web`, `npm run dev`, `npm run build`.
